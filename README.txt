KARKA AI & TECH ACADEMY — WEBSITE

Files
- index.html: page structure and content
- style.css: responsive styling and animations
- script.js: mobile navigation, FAQ accordion and small interactions
- assets/: logo and visual assets

Run locally
1. Extract this ZIP file.
2. Open the Karka-Redesign-Ready folder.
3. Double-click index.html to preview in Chrome or Edge.
   Recommended: open the folder in VS Code and use the Live Server extension.

Before publishing
- Verify course names, program details and Pay After Placement terms with Karka.
- Replace the official website/contact links if the organization provides different URLs.
- Connect any enrollment form or CTA to the actual application workflow.

The website is responsive and uses relative asset paths, so it can be previewed locally without a build step.
